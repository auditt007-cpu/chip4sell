口径说明：板型 / 496 / D3 D4 / Bxxx / JZ

板型（按芯片封装，不按型号首字母）：顶配 = 运存+存储在同一个 eMCP/uMCP 封装里，CPU 独立，整板 2 颗；盖子板 = 运存 PoP 叠在 CPU 上，存储独立，496/556-ball LPDDR5；三颗料 = CPU、运存、存储三颗完全独立，对应 200/178-ball 板型；存储 = 单颗 eMMC/UFS，本身不含运存，板型要看主板运存。

逐颗复核结果（499 行，498 个唯一型号，08EMCP08-EL3CV100 重复 1 行）：顶配 415、盖子板 58、三颗料 0、存储 19、待核 7。三颗料是板级布局，不是芯片型号；原先把 4DR/4CR/32-16/64-32、SDAD、TY、JY 当成三颗料是错的——4DR/4CR 是闪迪 SDADA4DR/4CR 的省写（eMCP），TY/SDAD/JY 也是 eMCP。库内暂无可证实的独立三颗料芯片；遇到 200 球三颗料板，请按实物球数/丝印另建型号。

待核：037/044/036/073/046 五个 BT 板码和 JY008/JW941 无公开料号，只有同价 eMCP 组旁证，未硬判；遇到时先看实物球数和丝印。

价格：最低回收价为主参考价；价2 为第二参考价，并列显示；缺一项就留空。“询价”表示该项暂无参考价。

496 / 556：都是 LPDDR5/5X 运存颗粒的 FBGA 球数；这次把 496/556 型号补进库，价2按基础容量价，其他容量写在备注和别名里，可按数字搜到。

D3 / D4：D3 = LPDDR3，D4 = LPDDR4X。D3 的 B809/B614 是 LPDDR3；D4 的 B425/B422/H9HP52AC 是 LPDDR4X。D3 里的 H9HQ52ACP 是 uMCP（LPDDR4X），单独按 uMCP 处理。

Bxxx：B614 / B809 / B425 / B422 是三星料号 hyphen 后的版本/封装后缀，同一后缀对应多个完整型号：B809 = KMRC1000BM-B809（3+64）/ KMRC10014M-B809（4+64）；B425 = KMDH/KMDP（4+64）/ KMDX（3+32）；B515 = KM3H6001CA / KM3H6001CM（6+64）；B625 = KMDC（4+64）/ KMDV（4+128）。

JZ：JZ 码用美光官方 FBGA 解码器逐个解出完整料号；JZ305=MT30AZZZCD9ZTPQS（uMCP 8+128，297-ball），JZ306/307=MT29VZZZBD9ZSKSM（uMCP 6+128，254-ball），JZ524/525=MTFC128G/256GAYAYHF（UFS 单颗 128/256GB），JZ242=MTFC256GARATEK（UFS 单颗 256GB）。
